# scripts/ — 部門をまたぐ共通スクリプト

## ai_image.py — OpenAI APIでの背景アート自動生成

各部のnoteサムネイル・Instagram画像・マガジン表紙の「背景の絵」を、OpenAIの画像生成APIで
自動生成するための共通スクリプト。タイトルや数値などの文字は焼き込ませず、背景だけを作る
（**ハイブリッド方式**）。文字・ランキング表は引き続き各部の `make_eyecatch.py` /
`make_ranking_table.py`（matplotlib）でこの背景の上に重ねる。理由: 生成AIは長文・日本語・
数値の描画を誤りやすく、開発2/4/6部のようにデータの正確性が重要な号でAI任せにするのは危険なため。

### 前提（社長がやること・支払い情報を扱うため代行不可）

1. https://platform.openai.com でOpenAIアカウントにログイン（ChatGPTと同じアカウントで可）
2. 組織の請求設定で支払い方法を登録（**ChatGPT Plusとは別の従量課金**。月額固定ではなく、
   生成した分だけ課金される）
3. https://platform.openai.com/api-keys で新しいシークレットキーを発行（表示は1回だけなのでコピー）
4. リポジトリ直下に `.env` を作成（`.env.example` をコピー）し、`OPENAI_API_KEY=` に貼る。
   `.env` は `.gitignore` 済みでコミットされない

### 使い方

```
python scripts/ai_image.py \
  --prompt "北海道の温泉と紅葉をイメージした、明るいクリーム地にテラコッタのアクセントの背景イラスト" \
  --orientation landscape \
  --out dev/4-onsen/omiyage/assets/2026-10/bg.png
```

- `--orientation landscape` = note用サムネ/表紙想定（1280x670にトリミング）
- `--orientation portrait` = Instagram想定（1080x1350にトリミング）
- 生成のたびに実費（数円〜数十円）がかかる。デザインを固めるまでの試行錯誤で複数回叩く前提だが、
  無闇に連打しない
- 各部の配色・モチーフ（例: 開発2部=紺+アンバー、開発4部=クリーム+テラコッタ、開発6部=グラファイト+緑/赤）を
  プロンプトに含めて、シリーズとしての統一感を保つこと

### 運用ルール

- **キーの発行・支払い方法の登録は社長が行う**（Claude/エージェントは代行しない。CLAUDE.mdの
  「外部への公開・投稿・課金・API送信は実行しない」に該当する行為のため）
- キーが `.env` に設定された後の生成実行（＝実費が発生する操作）は、社長の依頼を受けてClaude Codeが行ってよい
  （都度の少額課金であり、trade部のような自動売買とは性質が異なる）
- 生成した背景画像は各部の `assets/<期間>/` 配下に保存し、その上に文字を重ねた最終版を
  `eyecatch.png` 等として書き出す（背景そのものはSNS/noteに直接使わない）
