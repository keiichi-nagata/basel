# 0002 — 開発3部 ランキングの定義・データソース・自動化

日付: 2026-08-30
状態: 採用
関連: [[0001-mvp-is-drama]]

## 決定

### 1. クレーム
「話題のドラマ総合ランキング（合成指標）」とする。「視聴されている順番」「視聴数No.1」等、
横断視聴数を測定できているかのような断定はしない。

### 2. 合成式（MVP: 1〜4号）
TVer週間ランキング(A) + Netflix Japan 週間Top10(B) + Google検索トレンド(C) を
各 0〜100 に正規化し、**その作品に存在する要素だけの単純平均**。
A・Bの少なくとも一方に入っていることをランク付けの条件とする。
記事には合成スコアとA/B/Cの内訳を併記し、算出方法を毎号末尾に固定掲載。

### 3. アフィリエイト
VOD提携は現状 **ABEMA のみ**（A8経由）。U-NEXTはA8に案件が無く、
バリューコマース・アクセストレードは審査落ち。→ **もしもアフィリエイト・afb に申請**し、
通ればU-NEXT・Amazon Prime Videoをリンク化。未提携の配信先はテキスト表記のみ。
順位は配信先の有無で動かさない。

### 4. 自動化
収集は全自動（`dev/3-drama/pipeline/collect.*`、週次routine）。
TMDB(話数・あらすじ・配信状況) + Netflix Tudum + TVer + Google トレンド。
**公開前の人手レビュー（10分）は自動化しない**（会社ルール、スクレイパーのズレと事実誤認の防波堤）。

## 理由

- 横断視聴数の公式統合ランキングは日本に存在しない。合成指標＋算出方法の公開が
  唯一の誠実な出し方であり、それ自体が差別化（独自の切り口）になる。
- 収益化するランキング記事で根拠のない優良性表示は景表法リスク。
- MVPは無料で自動取得できる3ソースに絞り、視聴率・U-NEXT・Filmarksはv2で重み付け導入。

## 影響・保留事項

- NHK作品（大河・朝ドラ）はv1で原則圏外 → 記事に「民放＋配信が対象」と明記。
- Netflix Tudum / TVer は公式に開かれたAPIではない → 週1・低頻度・出典明記で運用し、
  仕様変更でスクレイパーが壊れる前提のメンテ枠を持つ。規約の最終確認は `sources.md` の表で管理。
- 収集スクリプトの実装言語は未確定（Python想定）。
