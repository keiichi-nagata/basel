# 0006 — 開発6部 資産クラス別 月間リターンランキングの新設と方法論

日付: 2026-09-11
状態: 採用
関連: [[0002-drama-ranking-methodology]]・[[0004-onsen-ranking-methodology]]・[[0005-trade-dept-auto-daytrade]]

## 背景

社長依頼（2026-09-11）「note に ○○ランキングを週刊か月刊で。例＝投資先の"今上昇中"ランキング」。
企画部で7案を採点（`planning/2026-09-11-investment-ranking.md`）し、
**I-002「資産クラス別 月間リターンランキング（円建て）＋AI考察」（20/25点）** を採用。
配属は社長判断で **開発6部として新設**（既存の 2部車・3部ドラマ・4部温泉と同じ「ランキング1系統＝1開発部」の型）。

## 決定

### 1. 位置づけ
- 月次・**無料**note。開発3部（ドラマ）と同じ**集客エンジン**。課金しない。
- 収益は回遊 → 証券口座・NISA・純金積立・ロボアド・暗号資産取引所などのアフィリエイト。
- エージェントは既存の `ranking-writer`、手順は `sop/ranking-magazine-workflow.md` を流用（新エージェント・新SOPは作らない）。

### 2. ランキングの定義
- 対象は10資産クラス（日本株/米国株/先進国株/新興国株/日本REIT/米国REIT/金/原油/先進国債券/ビットコイン）。
  リストは `dev/6-markets/universe.json`。
- 各クラスを代表する**東京市場上場の円建てETF等**の月末終値で計算する（為替換算不要・分配金を含まない＝価格リターン）。
  ビットコインは BTC-JPY の現物価格。
- 月間リターン ＝（対象月末終値 ÷ 前月末終値 − 1）×100。年初来 ＝ 前年12月末比。
- **指数のランキング表を他サイトから転載しない。終値から自分で計算する**（CLAUDE.md 絶対ルール）。
- ETFのため厳密な指数リターンとは一致しない旨を毎号明記。銘柄入れ替え時は `universe.json` とこのADRに追記。

### 3. 表現・コンプライアンス（最重要）
- 「上昇中」「今買うべき」「勝ち組資産」等の断定・推奨をしない。**過去の実績の提示**にとどめる。
- **個別の金融商品の売買推奨をしない。**
- 記事末尾に固定の免責（`sop/disclosure.md` 投資系の節）を必須化:
  過去実績であり将来を示さない／特定商品の売買推奨ではない・投資は自己責任／数値は終値からの自己算出（出典明記）。
- アフィリンクを含む号は冒頭に広告表記（PR）。口座開設アフィリは「入金・取引が成果条件」のものを避け、
  **開設のみで成果**になる案件を選ぶ（読者の不利益を作らない）。

### 4. なぜ無料か（金商法）
インターネットで誰でも随時アクセスできる**無料**のランキング記事は「投資助言・代理業」に該当しない
（不特定多数・随時取得可能なものは適用除外）。**有料会員制にはしない。個別性の高い助言もしない。**

### 5. 頻度
- **月刊**。月初に前月分。週刊化はしない（資産クラスは週次だとノイズが多く読者価値が低い）。
- 3/6/9/12月号は「直近3ヶ月の順位の入れ替わり」を振り返る四半期回にする。

### 6. 自動化
- 当面は手動（`collect.py` 実行 → 執筆 → 画像）。
- 反応が良ければ開発3部と同じく GitHub Action（月初 collect）＋ `/schedule` ルーチン（考察執筆＋PR）で半自動化。

## 理由

- 投信リターンランキングそのものは競合飽和＋主要データが二次利用禁止（企画 I-004＝却下）。
  「資産クラスを円建てで横断し、その月の物語を毎月やさしく解説する定期便」は空いている。
- 採点ロジックは開発2/3/4部の「一次データ→表→独自考察」を踏襲。データは終値から自己計算なので転載に当たらない。
- トレード部（個別株の短期売買）や開発5部（金融マンガ）とは階層が違い、共食いせず相互の導線になる。

## 影響・保留事項

- 証券・NISA・純金積立・暗号資産のアフィリは未提携。**初回（2026-08号）はアフィリなし・PR表記なしで公開**し、
  提携後の号から「口座・積立」節を追加する。もしも／afb の申請とあわせて A8 の金融案件を精査する。
- yfinance の終値は速報値。公開直前に `collect.py` を再実行して差分がないか確認する運用にする。
- ETF銘柄の一部（原油 1699.T、先進国債券 2511.T 等）は流動性がそれほど高くない。月末終値がNAVから
  大きく乖離していないかを目視チェックする。
