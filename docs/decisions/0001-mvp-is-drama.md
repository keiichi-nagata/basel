# 0001 — 今期のMVPは開発3部（ドラマランキング）

日付: 2026-08-29
状態: 採用

## 背景

開発部に4つの構想（アプリ有料note / 車 / ドラマ / 温泉）。ソロ運営で全部同時は不可能。
最初に「リサーチ→執筆→note→SNS→計測」の収益ループを1本通す対象を1つ選ぶ必要がある。

## 決定

開発3部（ドラマ・週次・無料マガジン + VODアフィリ）を今期MVPにする。
開発1部（有料note）は既存4本の実績があるため「新規開拓」ではなく「磨き込み + 導線強化」で並走。

## 理由

- 週次更新で「会社のリズム」が生まれ、SNSネタが途切れない
- ドラマ考察は Threads / Instagram と相性が良い（話題性・共感）
- VOD案件（U-NEXT等）は A8.net に在庫があり、既に審査通過済みのASPで完結できる
- 車（2部）は成約が遠くアフィリ相性が弱いため後回し
- 温泉（4部）は相性は良いが季節性があり、3部の型を流用すれば低コストで後追いできる

## 影響

- 温泉・車は Phase 2 以降。企画部は当面ドラマ関連の切り口深掘りに寄せる。
- A8以外のASP（もしも）の登録は Amazon/楽天リンクが要るタイミングで実施。
