# 0003 — 開発5部（中学生向け金融マンガ）を新設、開発1部は維持モードへ

日付: 2026-09-01
状態: 採用
関連: [[0001-mvp-is-drama]]

## 背景

開発1部（アプリ複製手順の有料note）は5本公開したが売れる気配がない。有料プロダクトの
主軸を、需要が見込める「中学生向け金融リテラシー教育マンガ」に移す。

## 決定

### 1. 開発5部を新設
- `dev/5-finance-manga/`。縦スクロールマンガ形式、noteの**有料マガジン**（序章＋全10回）
- コンセプト:「未来の自分に10万円を託すとしたら？」（提示された10回案の微修正版＝A案）
- 買い手は中学生ではなく保護者。マーケ・価格・タイトルはすべて親向けに設計
- エージェント `manga-edu-writer`、手順書 `sop/manga-episode-workflow.md`

### 2. 制作フロー（社長提案の4ステップ）
脚本（Claude/`manga-edu-writer`）→ 画像生成（Midjourney等・キャラ固定）→
編集・文字入れ（Canva・日本語テキストはここ）→ note掲載（序章〜第2回無料・以降有料）

### 3. 開発1部は維持モード
既存5本は残しサポートのみ。新規制作は停止。

### 4. 値付け
序章・第1・2回 無料／第3回以降 各¥200〜300／マガジン一括 ¥1,480前後。

## 理由

- 高校での金融教育必修化・新NISAで、保護者の「子に教えたい」需要が厚い
- 教育コンテンツは有料と相性が良い（無料集客の開発3部とは役割が別）
- 提示カリキュラムが既に高品質。ストーリー軸で中学生が飽きにくい

## リスクと対応

- **マンガの制作コスト**（他部門と違い絵が要る）→ キャラを2人に絞る、Midjourneyの
  `--cref`/`--sref`固定、バストアップ中心、崩れは許容/Canva補修/カット流用。
  まず序章〜第2回を無料で作り需要を確認してから絵に投資を厚くする
- **金商法・景表法**→ 一般教育に徹する（特定商品の推奨・個別助言なし）、毎回免責、
  詐欺の見抜き方を必須、未成年の口座は親権者同意が必要と明記
- **買い手の取り違え**→ 全設計を保護者向けに。各回に「保護者向けあとがき」

## 影響

- 会社の布陣: 開発3部＝無料集客エンジン、開発5部＝有料プロダクト主軸、開発1部＝維持。
- CLAUDE.md / docs/org.md / STATE.md / roadmap を更新。
