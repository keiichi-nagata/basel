## note でリンクを貼るときのルール

- [ ] 冒頭に広告表記（`sop/disclosure.md`）
- [ ] 無料マガジン記事のリンクは「その記事の内容と直接関係するもの」だけ。詰め込まない（スパム判定回避）
- [ ] Amazon / 楽天リンクは各社の規約に沿った方法で（note固有の制約がないか、貼る前に確認）
- [ ] 1記事あたりのリンク数は控えめに（目安3つまで）
- [ ] リンク切れ・提携終了を月1でチェック（`published/` の各記事）

## SNS でリンクを貼るときのルール

- [ ] 本文に広告表記
- [ ] 直リンクが規約上OKか（媒体により外部リンクの扱いが違う）。不可ならプロフィール経由に
- [ ] 「誘導 or PR」投稿は1日1本まで（`marketing/calendar.md` のルール）

## 禁止事項（自社ルール）

- 自己クリック・自己経由の購入
- 成果条件を満たさない誘導文（「無料」と書いて実際は有料 等）
- 体験していない製品の体験談
- ランキングの順位をアフィリ報酬で操作すること（順位は必ずデータ由来にする）
