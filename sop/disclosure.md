# SOP — 広告表記（ステマ規制対応）

## 前提

景品表示法の運用（2023年10月〜）で、事業者の広告なのに第三者の感想を装う表示は不当表示。
アフィリエイトは、事業者（＝あなた）が表示内容に関与している以上、広告として扱い明示する。
**判断に迷ったら表記する。** 表記しても失うものはない。

## いつ表記するか

- アフィリエイトリンクを含む note / SNS投稿 → **必ず**
- 有料note自体の宣伝（自社商品）→ 自社の宣伝と分かる文脈なら必須ではないが、曖昧なら入れる
- 提供・タイアップ案件 → 必ず（「提供: ◯◯」等も明記）

## どこに置くか

- note: タイトル直下・本文の冒頭（スクロールせず見える位置）
- Threads / Instagram: 本文中（末尾のハッシュタグに紛れさせない）。冒頭〜中盤が望ましい

## 定型文（コピペ用）

note 冒頭:
```
> この記事はプロモーション（アフィリエイトリンク）を含みます。
```

SNS 本文:
```
※本投稿はアフィリエイトリンクを含みます（PR）
```

リンクの直前:
```
〔サービス名〕 [PR]
```

## 投資・マーケット系note（開発6部・catalog #7-8 など）— 追加の免責

金融商品・相場に関する記事は、アフィリの有無に関わらず**末尾に固定の免責**を入れる:

```
## 免責
- 本記事の数値は〔終値／公開データ〕をもとに当社が算出・整理したものです（出典・取得日を記載）。
- 過去の実績であり、将来の成果を示すものではありません。
- 特定の金融商品の売買を推奨するものではありません。投資はご自身の判断と責任で行ってください。
```

- ランキング・比較記事は「上昇中」「今買うべき」「勝ち組」等の断定・推奨をしない（事実の提示にとどめる）。
- **無料公開を維持する**（不特定多数が随時読める無料記事は金商法の投資助言業に非該当）。有料会員制にしない。
- 口座開設アフィリは「入金・取引が成果条件」のものを避け、開設のみで成果になる案件を選ぶ。
