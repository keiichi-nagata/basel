# Instagram — 開発5部（金融マンガ）の告知に使用

## 状態: 手動投稿から開始。将来は Instagram Content Publishing API で自動化。

## いま最優先：カルーセル投稿（マンガと相性が最高）

Instagramのフィードは**カルーセル（最大20枚）**が使える。縦スクロールマンガをそのまま
スライドとして投稿できる。開発5部の告知はこれをメインにする。

- 画像サイズ: **1080×1350（4:5 縦）**。Canvaの各ページがそのまま使える
- 使うコマ: **無料回（序章・第1回）**か、有料回の**無料部分だけ**。有料部分は載せない
- カルーセルの最後に **CTAカード**（`dev/5-finance-manga/assets/ig-cta.png`）を1枚追加
  → 「続きはプロフィールのリンクから（note・無料）」。文言変更は `assets/make_ig_cta.py`

## キャプション（テンプレ）

```
中学生向けの金融マンガ、○○回を公開しました。
「（その回のフック1行）」

お小遣い・ゲーム・推し活のたとえで、"稼ぐ・守る・増やす" を親子で。
👉 続きはプロフィールのリンクから読めます（序章・第1回は無料）

#金融教育 #おうち学習 #中学生 #子育て #新NISA #マネー教育 #親子で学ぶ #お金の勉強
```

- Instagramはキャプション内のURLがリンクにならない → **必ず「プロフィールのリンクから」**
- **プロフィールのリンク（bio）** を note のマガジンURLに設定しておく
- アフィリンクを含む回は末尾に「#PR」表記（`sop/disclosure.md`）。今は無し

## ストーリーズ

- 見出し画像（`assets/0X/eyecatch.png`）を1枚 → **リンクスティッカー**で note へ直リンク
- カルーセル投稿後に「新しい投稿」のスタンプでフィードへ誘導

## 手動投稿の手順

1. スマホの Instagram アプリ →「＋」→「投稿」
2. カメラロールから、その回のコマ画像を**順番に**複数選択（＋ 最後に `ig-cta.png`）
3. 加工なしで「次へ」→ キャプション（上のテンプレ）を貼る
4. 位置情報なし、タグ付けなし → シェア
