# 開発7部 — 資産形成note（2026-09-19 新設）

## 役割

資産形成全般をテーマにしたテキスト中心のnoteシリーズを発信する。特定の読者層・商品に限定せず、
今後は子育て世代・独身・シニア等、対象を変えた複数シリーズを並行して展開する想定。

## 現在のシリーズ

### 【月5万円】子育て世代の王道資産形成（3部作）

- 第1回（無料）: 今すぐ始める！家計見直しとライフプランの作り方
- 第2回: 失敗しにくい王道投資（NISA・iDeCo・暴落時の対策）
- 第3回: 貯めるより難しい？子育て世代の失敗しない「出口戦略」〜資金を安全に取り崩す完全ガイド〜

第1回は無料公開。第2回・第3回の価格・無料範囲は執筆時に社長と決定する。

noteマガジンは、現状このシリーズと同名「子育て世代の王道資産形成」として作成する
（`magazine-description.md`参照）。今後、別の読者層向けシリーズを始める際は、同じマガジンに
混ぜるか別マガジンを新設するか、その都度判断する。

## フォルダ

- `affiliates.json` — シリーズ横断で使うアフィリンク（現状: 通信費〈auひかり〉・車の維持費
  〈アース・カー／ニコノリ〉）
- `drafts/` — `01.md`（子育て世代シリーズ第1回）等の下書き。今後シリーズが増えたら
  サブフォルダで分ける想定（例: `drafts/kosodate/`）
- `published/` — 公開記録
- `magazine-description.md` — noteマガジンの名前・説明文（コピペ用）
- `assets/` — 画像一式（他部と同じハイブリッド方式: `scripts/ai_image.py`で生成した固定背景
  `bg-note.png`/`bg-ig.png`＋matplotlibで文字を重ねる）
  - `make_cover.py` → `magazine-cover.png`（マガジン表紙）
  - `make_eyecatch.py` → 記事ごとの`eyecatch.png`(note)/`eyecatch-ig.png`(IG)。
    配色は深いティールグリーン×ゴールド（他部と差別化）

## 注意

- 金融商品（NISA・iDeCo等）に触れる内容のため、`sop/disclosure.md`の「投資・マーケット系note」の
  追加免責（末尾の免責文、断定的な推奨をしない）を適用する
- アフィリンクを含む記事には必ず広告表記（`sop/disclosure.md`）
