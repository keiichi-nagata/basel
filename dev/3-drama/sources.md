# 開発3部 データソース

## 原則

- **一次ソースを使い、出典URLと取得日を必ず残す**（`data/` と draft の両方に）。
- 他サイトのランキング表そのものを転載しない。数値は引用の範囲、順位付けの解釈・考察はオリジナル。
- スクレイピングする場合は対象サイトの利用規約と robots.txt を確認。規約でNGなら手入力。

## 候補（各自で規約確認のうえ採否を記入）

| ソース | 内容 | 取得方法 | 規約確認 | 採否 |
|---|---|---|---|---|
| 各配信サービスの公式「今週のランキング」 | 配信視聴の人気 | 手動 / 公式が出すなら引用 | 未 | |
| 番組公式・制作会社のプレスリリース | 視聴率・配信数の公式発表 | 手動 | 未 | |
| 世帯/個人視聴率の報道（各社ニュース） | リアタイ視聴率 | 引用（出典明記） | 未 | |
| SNSの話題量（自前集計） | 反響の大きさ | 自分で件数カウント | 自前なのでOK | |

## 週次データの記録フォーマット（`data/YYYY-Www.json` 等）

```
{
  "week": "2026-W36",

  "items": [
    {"rank": 1, "title": "", "prev_rank": null, "metric": "", "value": "", "source_url": ""}
  ]
}
```
