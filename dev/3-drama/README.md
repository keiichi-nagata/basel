## ワークフロー

`sop/ranking-magazine-workflow.md` に従う。要点:

1. `ranking-writer` にランキング + 前週比 + 考察ドラフト + SNS文面3〜5本を作らせる
2. 社長がファクトチェック（順位・作品名・数字・出典）
3. ネタバレ配慮（最新話の核心は伏せる or 明示的に警告）
4. 冒頭に広告表記（`sop/disclosure.md`）
5. VODアフィリンクは「その週に触れた作品が見られる配信サービス」に限定して自然に置く
6. note公開 → マーケ部へSNS文面を引き渡し（`marketing/threads/queue.md`）
7. `published/` にメタ記録、`finance/kpi.csv` に初速メモ
