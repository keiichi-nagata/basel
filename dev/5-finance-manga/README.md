# 開発5部 — 中学生向け金融リテラシー教育マンガ（有料マガジン）

## 成果物

縦スクロールマンガ形式の教育コンテンツ。noteの**有料マガジン**（序章＋全10回）。
コンセプト:「未来の自分に10万円を託すとしたら？」というストーリーを軸に、
お小遣い・ゲーム・推し活・身近な企業のたとえで「稼ぐ／守る／増やす」を学ぶ。

## 誰に売るのか（重要）

**買い手は中学生本人ではなく、その保護者（親・祖父母）や教員。**
- タイトル・説明・価格・マーケは「子どもに金融を教えたい大人」向けに設計する
- マーケは教育・子育て界隈（Threads/Instagram/note）。10代向けSNSではない
- 各回に「保護者向けあとがき」を入れて、買い手の安心と納得を上げる

## 制作フロー（`sop/manga-episode-workflow.md`）

1. **脚本**: `manga-edu-writer` エージェントが、疑問役（ミオ）×解説役（センセ）の対話台本を
   コマ単位で作成（12〜18コマ）。画像プロンプト・図解リスト・保護者あとがき・免責つき
2. **画像生成**: Midjourney等で、`characters.md` の基準プロンプト＋`--cref`/`--sref` 固定で
   コマごとに生成（バストアップ中心・服装固定・細部の差異は許容）
3. **編集・文字入れ**: Canva に画像を並べ、吹き出し・セリフ・図解を追加 → スマホ用の縦長画像で書き出し
   （1エピソード=複数枚に分割。日本語テキストはすべてここで入れる）
4. **note掲載**: 記事内に縦スクロールで貼付。序章〜第2回は無料、第3回以降を有料ラインに。マガジンに追加

## 値付け（たたき台）

| 区分 | 内容 |
|---|---|
| 序章・第1回・第2回 | 無料（試し読み・集客） |
| 第3回〜第10回 | 各 ¥200〜300 |
| マガジン一括 | ¥1,480前後（全話読める） |

親は「品質を見てから買う」。無料枠の完成度が売上を左右する。

## 絶対に守ること（`sop/manga-episode-workflow.md` に詳細）

- 特定の金融商品・銘柄の推奨、個別の投資助言はしない（一般教育に徹する）
- 毎回末尾に免責文（`disclaimer` は template に組込み済み）
- 「絶対儲かる」を否定し、リスクと詐欺の見抜き方を必ず扱う
- 未成年の証券口座開設・投資は親権者の同意が必要、という現実を本文で明示
- アフィリンクを入れる回は広告表記（`sop/disclosure.md`）

## フォルダ

- `curriculum.md` — 全11本（序章＋10回）の学習ゴールと構成（A案 微修正版）
- `characters.md` — キャラクターバイブル＋Midjourney基準プロンプト＋絵柄トンマナ
- `template.md` — 1話の脚本フォーマット
- `scripts/` — `00-prologue.md` 〜 `10-*.md`（作業中の脚本）
- `assets/` — 生成画像・Canva書き出し（`assets/raw/` は gitignore、公開用の縮小版のみコミット）
- `published/` — 公開記録（URL・価格・初速）
