# 開発5部 — 中学生向け金融リテラシー教育マンガ（有料マガジン）

## 成果物

縦スクロールマンガ形式の教育コンテンツ。noteの**有料マガジン**（序章＋全10回）。
コンセプト:「未来の自分に10万円を託すとしたら？」というストーリーを軸に、
お小遣い・ゲーム・推し活・身近な企業のたとえで「稼ぐ／守る／増やす」を学ぶ。

## 誰に売るのか（重要）

**買い手は中学生本人ではなく、その保護者（親・祖父母）や教員。**
- タイトル・説明・価格・マーケは「子どもに金融を教えたい大人」向けに設計する
- マーケは教育・子育て界隈（Threads/Instagram/note）。10代向けSNSではない
- 各回に「保護者向けあとがき」を入れて、買い手の安心と納得を上げる

## 制作フロー（`sop/manga-episode-workflow.md`）

1. **脚本**: `manga-edu-writer` エージェントが、疑問役（ミオ）×解説役（センセ）の対話台本を
   コマ単位で作成（12〜18コマ）。画像プロンプト・図解リスト・保護者あとがき・免責つき
2. **画像生成**: Midjourney等で、`characters.md` の基準プロンプト＋`--cref`/`--sref` 固定で
   コマごとに生成（バストアップ中心・服装固定・細部の差異は許容）
3. **編集・文字入れ**: Canva に画像を並べ、吹き出し・セリフ・図解を追加 → スマホ用の縦長画像で書き出し
   （1エピソード=複数枚に分割。日本語テキストはすべてここで入れる）
4. **note掲載**: 記事内に縦スクロールで貼付。序章〜第2回は無料、第3回以降を有料ラインに。マガジンに追加

## マガジン設定

- **種類**: 無料マガジン。
  - noteは「マガジンの種類（無料/有料）」は後から変更不可。ただし**無料マガジンの中に有料記事を入れられる**。
  - なので 序章・第1回＝無料記事、第2回〜＝有料記事を、同じ無料マガジンに追加していく。
  - 「全話パック ¥1,480」をやるなら、売れ行きを見てから**別途 有料マガジンを新規作成**し、有料回をそこにも入れる（1記事は複数マガジンに所属可）。
- **マガジン名（候補）**: 「未来の自分に10万円を託す ─ 中学生からの金融の授業」／短め「中学生からの金融の授業」
- **説明文（コピペ用）**:
  > お小遣い・ゲーム・推し活のたとえで、中学生が飽きずに読める金融リテラシーのマンガ講座（序章＋全10回）。「稼ぐ・守る・増やす」をやさしく、そして「絶対儲かるは詐欺」というお金の守り方まで。各回に保護者向けのあとがきつき。
  > ※金融教育を目的とした一般的な情報であり、特定の金融商品の推奨や投資助言ではありません。
- **見出し画像**: `dev/5-finance-manga/assets/magazine-cover.png`（`make_cover.py` で再生成可）

## 値付け

| 区分 | 内容 |
|---|---|
| 序章・第1回 | **全文無料**（試し読み・集客） |
| 第2回〜第10回 | 各記事、冒頭〜図解の手前まで無料 → そこに**有料ライン**。単体 **¥200**（反応を見て調整） |
| マガジン一括 | ¥1,480前後（全話読める。売れ行きを見て別途 有料マガジンで） |

親は「品質を見てから買う」。無料枠（序章＋第1回）で「買う価値あり」と思わせる。
有料回は「無料部分だけでも1つ学びが完結する」構成にして、続きを読みたくさせる。

## 絶対に守ること（`sop/manga-episode-workflow.md` に詳細）

- 特定の金融商品・銘柄の推奨、個別の投資助言はしない（一般教育に徹する）
- 毎回末尾に免責文（`disclaimer` は template に組込み済み）
- 「絶対儲かる」を否定し、リスクと詐欺の見抜き方を必ず扱う
- 未成年の証券口座開設・投資は親権者の同意が必要、という現実を本文で明示
- アフィリンクを入れる回は広告表記（`sop/disclosure.md`）

## Canva組み立て手順（序章の実作業）

1. **canva.com** をブラウザで開く → Google/メールで登録（**無料プランでOK**）
2. 「デザインを作成」→「カスタムサイズ」→ **幅1080 / 高さ1350 px** →作成
3. 左メニュー「アップロード」→ コマ画像（koma01〜16）＋ `assets/00/zu1-umaibou.png` ＋ `assets/00/shime.png` を全部アップロード
4. コマ画像をキャンバスにドラッグ → 幅いっぱいに調整。1ページに2〜3コマ縦積み
5. 左「素材」→「ふきだし」で吹き出しを乗せる（王冠マーク＝有料は避ける）→「テキスト」でセリフ入力（フォントは「ラウンド」検索、サイズ24〜32）
6. 「＋ページを追加」で続ける。コマ10の後に図1を1ページ、最後に締めコマ
7. 右上「共有／ダウンロード」→ **PNG** →全ページ保存（page1.png〜）
