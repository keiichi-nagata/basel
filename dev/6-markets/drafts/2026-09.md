## 9月に何が効いたか

### 全体の背景：9月16日のFOMCで3年ぶりの利上げ

9月の資産クラスの動きを理解するには、まず9月16日のFOMC（米連邦公開市場委員会）を押さえる必要があります。
FRBは政策金利を0.25ポイント引き上げ3.75〜4.00%とし、これは2023年7月以来はじめての利上げでした
（採決は12対0の全会一致）。背景には、8月のPCEインフレ率が前年比3.8%（コアは3.4%）と高止まりしている
ことがあり、公表された議事要旨（10月7日公開）では、年内にもう一段の利上げが「適切になりそうだ」との
見方が大勢だったと report されています。この「インフレが高止まりする中での利上げ」という構図が、
金・株式・債券・REITの多くに共通する逆風になりました。

### 1位・2位：株や債券と違う理由で動いたもの

**原油（+5.7%）** は中東情勢の緊迫化が材料でした。9月上旬にはイラク領海でのタンカー攻撃やイラン革命
防衛隊によるペルシャ湾での船舶への攻撃が報じられ、月の後半にはフーシ派によるサウジアラビアへの攻撃や、
米国・イランの交渉が行き詰まったとの報道が供給不安を強めたと report されています。年初来では+79.4%と、
10資産の中で突出して高いリターンが続いています。

**ビットコイン（+4.9%）** は月の後半にかけて値を戻しました。8月19日からの上昇が続く形で、9月下旬には
一時8万7千ドル台まで上昇し、1月以来の高値を回復したと report されています。背景には、ビットコイン
ETFへの資金流入が9月終盤に強まったこと（9月26日までの週は年間最大の流入）、空売りの強制決済（ショート
スクイーズ）があったことなどが挙げられています。ただし月前半はETFからの資金流出が続いていた時期もあり、
月を通じて一方向だったわけではないと report されています。円建ての年初来では依然▲4.1%で、2025年の
高値からの調整が続いている状態です。

### 株式：日本が最上位も全面マイナス、金利上昇とドル高が重荷

9月は株式4クラスすべてがマイナスでした。**日本株（TOPIX、▲0.5%）** が株式の中では最も底堅かったものの、
外部の市場レポートでも9月のTOPIXは半年ぶりに下落に転じたと report されており、外需・金融・ディフェンシブ
銘柄の弱さが指摘されています。原油高によるインフレ懸念と、世界的な長期金利の上昇が重荷になったという
見立てです。

**米国株（S&P500の円建て、▲2.0%）** は中東情勢への警戒とヘルスケア株の下落（月初）、月末にかけては
インフレ再燃への警戒と10月利上げ観測の高まりを受けた長期金利の上昇が重荷になったと report されています。
いわゆる「9月効果」（米国株が季節的に弱くなりやすいという経験則）への言及も見られました。

**新興国株（▲1.6%）・先進国株（▲2.9%）** はいずれもマイナスながら、新興国株は8月の6位から9月は4位に
順位を上げています。FOMCの利上げでドルが強くなる場面は新興国株には一般に逆風ですが、今回は米国株・
先進国株の下げの方が大きく、相対的に順位が上がった形です。

### 下位：金利上昇に弱いもの（債券・REIT）、そして金の急落

**先進国債券（▲4.0%）** と **日本REIT（▲4.4%）・米国REIT（円建て、▲6.4%）** は、いずれも金利上昇に
弱い資産クラスです。FOMCの利上げと、年内のさらなる利上げ観測の高まりを受けて長期金利が上昇し、利回りで
比較される債券・REITが売られたと report されています。

**金（▲7.3%）が、今回いちばん大きな動きです。** 8月は+7.7%で3位につけていた金が、9月は一転して
▲7.3%の最下位に転落しました。この順位の落差（3位→10位）が今号の最大の変動です。要因として複数の
市場レポートが共通して挙げているのは次の3点です。

- **利上げ観測・利上げそのものによる金利上昇**: 9月16日のFOMC利上げに加え、9月24日にはNY連銀の
  ウィリアムズ総裁が年内のさらなる利上げの可能性に言及したと report されており、金利のつかない金の
  相対的な魅力が薄れたとされています。
- **ドル高**: 利上げ観測を受けてドルが強含み、ドルベースで見た金が割高になったことが売り材料になったと
  report されています。
- **原油高によるインフレ懸念との「合わせ技」**: 通常は地政学リスク（中東情勢）は金にとって買い材料に
  なりやすいものですが、9月は「原油高→インフレ懸念→利上げ観測→金利上昇」という流れが金利上昇の
  ほうを強めてしまい、金には逆に売り材料として働いたと report されています。

つまり9月の金は、「中東情勢の悪化」という同じニュースが、原油にはプラス、金にはマイナスに働いた
珍しい月でした。地政学リスク＝金高、とは限らないことがよく分かる1ヶ月です。

## 定点観測：1位を当てにいかなくてもいい

今回から前月（8月）との順位比較ができるようになりました。見てわかる通り、**1位・2位は入れ替わっただけ
（原油とビットコインが順位を交代）ですが、3位だった金は一気に最下位（10位）に転落**しています。前月
3位という「悪くない順位」から、翌月に10資産中最下位になるまで、1ヶ月しかかかりませんでした。

逆に新興国株（6位→4位）や先進国株（7位→6位）、先進国債券（8位→7位）、日本REIT（9位→8位）、米国REIT
（10位→9位）は、絶対のリターンはマイナスのままでも順位は少しずつ上がっています。月間リターンの絶対値
だけでなく、他の資産と比べた「相対的な位置」も毎月変わるということです。

毎月「今いちばん上がっている資産」を追いかけて乗り換えるのは、当てにいく難しさに加えて売買のたびに
コストと税金がかかります。8月の3位が9月の最下位になった今回の金のように、**前月の順位は翌月を
保証しません**。複数の資産クラスに分けて積み立てていれば、その月の勝ち資産を外しても全体では
取りこぼしにくい——このランキングは「次に何を買うか」の表ではなく、「自分の分散がどう効いているか」を
毎月確かめる表として使うのがおすすめです。

## このランキングの作り方

各資産クラスを代表する東京市場上場の円建てETF等（日本株＝TOPIX連動の1306.T、米国株＝S&P500の1655.T、
金＝純金上場信託の1540.T、原油＝原油インデックスの1699.T……）の月末終値をもとに、前月末比の騰落率で
並べています。ETFのため指数そのものの騰落とは厳密には一致せず、分配金も含みません（価格リターン）。
特定の資産・商品を推奨するものではありません。
