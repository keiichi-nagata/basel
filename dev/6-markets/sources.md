# 開発6部 資産クラス別 月間リターンランキング — データソース（確定版 v1）

決定経緯: `docs/decisions/0006-market-ranking-methodology.md`。

## クレーム

- ○「〔月〕の資産クラス別 月間リターンランキング（円建て）」「騰落率が高い順」
- ✕「上昇中」「今買うべき」「勝ち組資産」等の断定・推奨。✕ 個別銘柄の売買推奨

## 対象と算出

| 項目 | 内容 |
|---|---|
| 対象クラス | `universe.json` の10クラス（日本株/米国株/先進国株/新興国株/日本REIT/米国REIT/金/原油/先進国債券/ビットコイン） |
| 価格の取り方 | 各クラスを代表する**東京市場上場の円建てETF等**の日次終値（yfinance、auto_adjust）。ビットコインは BTC-JPY の現物価格 |
| 月末終値 | その月の最終営業日の終値（月次リサンプルの last） |
| 月間リターン | （対象月末終値 ÷ 前月末終値 − 1）× 100（％）。小数第2位 |
| 年初来リターン | （対象月末終値 ÷ 前年12月末終値 − 1）× 100（％） |
| 為替 | 換算しない（対象がすべて円建て銘柄のため） |
| 分配金 | 含まない（価格リターン。記事に明記する） |

- 「指数のランキング表」を他サイトから転載しない。**終値から自分で計算**する（CLAUDE.md 絶対ルール）。
- ETFの選定は「その指数への連動を目的とした代表的な1本」。乖離・信託報酬の影響は軽微だが、
  厳密な指数リターンとは一致しないことを記事に一言添える。
- 銘柄を入れ替えたら `universe.json` の更新と `docs/decisions/0006` への追記を必須にする。

## 出典の書き方

- 記事・データJSONに「ティッカー」「取得日」「どの指数に連動するETFか」を明記。
- 例:「日本株＝TOPIX連動ETF（1306.T）の月末終値より算出。2026-09-11取得」。

## 考察の材料（AI考察ブロック）

- その月の主な出来事は WebSearch で確認（FOMC・日銀会合・雇用統計・CPI・原油/OPEC・
  地政学イベント・暗号資産の固有ニュース）。憶測は書かず「〜が背景と report されている」と要約。
- 定点観測: 「1位を当てにいかなくても、分散していれば取りこぼさない」を毎回の締めに置く。
- 四半期の節目（3・6・9・12月号）は「直近3ヶ月の順位の入れ替わり」を振り返る。

## コンプライアンス

- **無料公開を維持**（金商法の投資助言・代理業の適用除外＝不特定多数・随時取得可能）。有料化しない。
- 記事末尾に固定の免責（`sop/disclosure.md` 投資系の節）:
  - 過去の実績であり将来を示すものではない
  - 特定の金融商品の売買を推奨するものではない／投資判断は自己責任
  - 数値は終値をもとに当社が算出（出典・取得日を記載）
- アフィリンクを含む号は冒頭に広告表記（PR）。口座開設アフィリは「入金・取引が成果条件」の
  ものを避け、開設のみで成果になるものを選ぶ（読者の不利益を作らない）。
