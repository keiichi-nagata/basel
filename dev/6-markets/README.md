# 開発6部 — 資産クラス別 月間リターンランキング & AI考察

## 成果物

月次・**無料**note（マガジン「**資産クラス別 月間リターンランキング（月刊）**」）。
毎月、主要な資産クラスを**円建て**で並べ、前月の騰落率でランキング化し、「なぜその順位だったか」と
「積立を続けている人はこの1ヶ月をどう受け止めるか」を解説するエッセイをつける。

開発3部（ドラマ）と同じ**集客エンジン**の位置づけ。課金はしない。回遊を作って
証券口座・NISA・純金積立・ロボアド・暗号資産取引所などのアフィリエイトで回収する。
決定経緯: `docs/decisions/0006-market-ranking-methodology.md`。

## 対象の資産クラス（`universe.json`）

日本株 / 米国株 / 先進国株 / 新興国株 / 日本REIT / 米国REIT / 金 / 原油 / 先進国債券 / ビットコイン の10クラス。
各クラスは**東京市場に上場する円建てETF等の月末終値**でリターンを計算する（為替換算不要・
分配金は含まない＝価格リターン）。指数そのものの転載はしない。銘柄の入れ替えは `universe.json` と
`docs/decisions/0006` に記録する。

## ランキングの定義（重要）

- 月間リターン ＝ （対象月末の終値 ÷ 前月末の終値 − 1）× 100（％）。年初来は前年12月末終値が基準。
- 「上昇中」「勝ち組」等の煽り表現は使わない。**過去の実績の提示**にとどめる。
- **特定の金融商品の売買推奨はしない。** 順位は事実（終値から計算した騰落率）のみ。
- 数値には必ず出典（ティッカー・取得日）を添える。免責は `sop/disclosure.md` の投資系の節。

## なぜ無料か（金商法）

インターネットで誰でも随時アクセスできる**無料**のランキング記事は「投資助言・代理業」に該当しない
（不特定多数・随時取得可能なものは適用除外）。有料会員制にはしない。個別性の高い助言もしない。

## フォルダ

- `universe.json` — 対象クラスと連動ETF（ティッカー）
- `pipeline/collect.py` — yfinanceで終値取得 → 月間/年初来リターンを計算 → `data/YYYY-MM.json`
- `sources.md` — データソース・算出方法・コンプライアンス（確定版）
- `template.md` — note雛形
- `data/` — `YYYY-MM.json`（順位・騰落率・終値・取得日）
- `drafts/` — `YYYY-MM.md`（下書き）＋ `YYYY-MM.png`（ランキング表画像）
- `published/` — `YYYY-MM.md`（公開記録）
- `assets/make_ranking_table.py` — 表画像（グラファイト＋緑/赤）
- `assets/make_eyecatch.py` — 各号サムネイル（note 1280x670 ＋ IG 1080x1350）
- `assets/make_cover.py` — マガジン表紙（`assets/magazine-cover.png`）

## 毎月の流れ（`sop/ranking-magazine-workflow.md` 準拠）

1. 月初、前月分を対象に `python dev/6-markets/pipeline/collect.py YYYY-MM`
2. `python dev/6-markets/assets/make_ranking_table.py YYYY-MM` で表画像
3. `drafts/YYYY-MM.md` を `template.md` の形で執筆（考察は WebSearch でその月の出来事を確認）
4. `assets/make_eyecatch.py "YYYY年M月" dev/6-markets/assets/YYYY-MM` でサムネイル
5. 社長レビュー（出典・免責・煽り表現の有無）→ note公開 → マガジン追加 → 承認フローでSNS告知
6. `published/YYYY-MM.md` にURL・初速

## 独自の切り口（AIに任せない = このマガジンの価値）

騰落率の羅列で終わらせず、**その月に何が効いたか**（金利・為替・原油・地政学・金融政策・
暗号資産の固有要因）を1つずつ言葉にし、**「分散していれば1位を当てにいく必要はない」**という
積立投資家の目線に毎回つなぐ。四半期ごとに「順位の入れ替わり」を振り返る回を挟む。
