# 開発4部 — エリア別お土産ランキング（温泉宿ランキングの対）

## これは何か

毎月の温泉宿ランキング（`dev/4-onsen/`）と**同じエリア**の「定番お土産TOP5」。
**温泉宿ランキングと同じやり方**（社長方針 2026-09-10）:

- 独自採点＝**楽天市場レビュー評価 ＋ Amazonレビュー評価**の単純平均（宿の「楽天トラベル＋じゃらん」の置き換え）
- レビューは体験談化せず第三者視点で要約
- 価格は幅で（変動するため）
- アフィリエイトは**温泉宿ランキングと同じリンク**（`../affiliates.json` の `generic`）を末尾に。
  個別商品の楽天市場リンクは楽天アフィリエイト（提携済み）で発行して `drafts/` に直接埋める

## フォルダ

- `sources.md` — 採点方法・レビュー要約ルール・アフィリ対応
- `template.md` — note雛形
- `data/YYYY-MM.json` — 候補商品データ（評価点・件数・出典URL）
- `drafts/YYYY-MM.md` — 下書き ＋ `YYYY-MM.png`（ランキング表画像）
- `published/YYYY-MM.md` — 公開記録
- `make_ranking_table.py` — `data/YYYY-MM.json` から表画像 `drafts/YYYY-MM.png` を生成（緑ヘッダー）
- `assets/YYYY-MM/` — サムネイル。親の eyecatch スクリプトを `omiyage` モードで呼ぶ:
  `python ../assets/make_eyecatch.py "2026年9月" "北海道のお土産編" dev/4-onsen/omiyage/assets/2026-09 hokkaido omiyage`
  （温泉宿と同じ明るい配色・モチーフ。タグラインだけ「楽天市場×Amazon 独自採点｜お土産ランキングTOP5」に差し替わる）

## 毎月の流れ

1. その月のエリア（`../areas.md`）を確認
2. 定番お土産を10〜15件リストアップ（楽天市場「〔エリア〕 お土産」／各種まとめ記事は参考のみ・転載しない）
3. 各商品の楽天市場・Amazonのレビュー点・件数を記録 → 20件以上・両方ありでスクリーニング
4. 独自採点でソート → 1ブランド1商品でTOP5
5. `data/YYYY-MM.json` → `make_ranking_table.py` → `drafts/YYYY-MM.md` を `template.md` の形で執筆
6. 社長レビュー（体験談化していないか・価格の幅・出典）→ note公開 →「温泉宿ランキング」と同じマガジンに追加

マガジンは「エリア別 温泉宿ランキング（月刊）」に相乗り（別マガジンは作らない）。
