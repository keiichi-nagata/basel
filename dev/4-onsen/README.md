# 開発4部 — エリア別温泉宿ランキング & AI考察

## 成果物

月次・無料note（マガジン「**エリア別 温泉宿ランキング（月刊）**」）。毎月1つのエリア（温泉地）を選び、
そのエリアの宿TOP5を独自採点で選出。
各宿の「良いところ・残念なところ」を口コミから要約し、楽天トラベル（個別宿＋汎用）・JTB旅行予約（汎用）の
アフィリエイトリンクを掲載する。

## ランキングの定義（重要）

**楽天トラベルの宿泊者評価 ＋ じゃらんの宿泊者評価（各5点満点）の単純平均**を「独自採点」とする。
実際に宿泊した体験ではなく、公開されている口コミ・評価データの合成であることを常に明記する。
「一番人気」「絶対おすすめ」のような断定はしない。詳細と根拠は `sources.md`、決定経緯は
`docs/decisions/0004-onsen-ranking-methodology.md`。

## 口コミの書き方（重要・コンプライアンス）

**「自分が宿泊してきたかのような一人称の体験談」は書かない。** 実際に宿泊していない体験を
事実として書くことは、景品表示法のステマ規制・優良誤認表示のリスクがある（アフィリエイトリンク付きだと
なおさら）。「口コミでは〜という声が多い」「一方で〜という指摘も」という**第三者視点の要約**で書く。
詳細は `sources.md` の「口コミの要約ルール」。

## エリアの選び方

**楽天トラベルのアフィリエイト提携が持つ12エリア区分**（北海道・東北・北関東・甲信越・北陸・首都圏・
東海・近畿・山陽山陰・四国・九州・沖縄）に合わせる。汎用リンクもエリア単位で用意されているため運用しやすい。
TOP5はエリア内の都道府県をまたいで選ぶ（例: 北海道エリアなら登別・洞爺湖・定山渓などから横断）。
実施順・季節適性は `areas.md` に記載。知名度・検索需要・温泉宿の候補の厚みを見て順序を調整する
（例: 沖縄は温泉宿の候補が薄く台風シーズンとも重なるため後回し）。

## 更新サイクル

- 月次。毎月初旬に翌月のエリアを確定 → リサーチ → 中旬ごろ公開（`sop/ranking-magazine-workflow.md`）
- 所要目安: リサーチ（`ranking-writer`）→ 社長レビュー → 公開

## フォルダ

- `sources.md` — 採点方法・口コミ要約ルール・アフィリエイト対応表（確定版）
- `template.md` — note雛形
- `areas.md` — エリアのローテーション計画
- `affiliates.json` — **汎用**の楽天トラベル・JTB旅行予約バナーリンク（個別宿の楽天トラベルリンクは
  月ごとに変わるため、ここではなく `drafts/<期間>.md` に直接記載する）
- `data/` — 月次の候補宿データ（評価点・出典URL。`YYYY-MM.json`）
- `drafts/` — `YYYY-MM.md`（下書き）＋ `YYYY-MM.png`（note/SNS貼付用のランキング表画像）
- `published/` — `YYYY-MM.md`（公開記録）
- `assets/make_ranking_table.py` — `data/YYYY-MM.json` からランキング表画像を生成（note で
  Markdown表が崩れるため、開発3部と同様に画像で貼る）
- `assets/make_cover.py` — マガジン表紙画像（`assets/magazine-cover.png`）。**他部と違う明るい配色**
  （クリーム地＋テラコッタ）で差別化
- `assets/make_eyecatch.py` — 各号のサムネイル画像（`assets/YYYY-MM/eyecatch.png`）。表紙と同じ配色

価格は掲載しない（変動が激しく確認の手間が大きいため。予約リンク先で確認してもらう）。

## ワークフロー

`sop/ranking-magazine-workflow.md`（月次）に従う。開発2/3部と異なり**自動収集パイプラインは無い**
（温泉宿の評価はWebSearchでの都度リサーチが前提）。`ranking-writer` が候補宿を洗い出し→評価点を
記録→TOP5選出→執筆、まで担当する。

## 独自の切り口（AIに任せない = このマガジンの価値）

点数の羅列で終わらせず、口コミの中の**具体的な指摘**（部屋の広さ・食事・接客・貸切風呂の空き状況・
アクセスなど）を拾い上げて要約し、「どんな人に向いているか」を宿ごとに明示する。

## アフィリエイト

- 各宿: 楽天トラベルの当該宿ページへの**個別**アフィリエイトリンク（楽天アフィリエイト提携済み。
  TOP5確定後に発行）
- 記事内に**汎用**テキストリンク: 楽天トラベル＋JTB旅行予約（首都圏発・A8経由）。両方 `affiliates.json`
  に登録済み
- リンクは**テキストリンク**で統一（バナー画像のHTMLはnoteに貼れないため）
- 広告表記は必須（`sop/disclosure.md`）
