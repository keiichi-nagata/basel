# 開発1部 — アプリ開発 + 有料note

## 役割

GitHubで動くWebアプリを作り、「ソースを複製して自分用に使えるようにする手順」を有料noteで販売する。

## 現状

有料note 4本公開済み。5本目を準備中。詳細は `catalog.md`。

## パイプライン（`pipeline/` に作業物を置く）

1. **企画** — 企画部のネタ or 自分の課題から。1テーマ1リポジトリ。
2. **実装** — アプリ本体。デプロイ先まで動く状態にする（社長が動作保証）。
3. **複製手順の言語化** — `app-note-writer` エージェントに草稿を作らせる:
   - 前提（アカウント、無料枠の範囲、必要な環境）
   - フォーク/クローン手順
   - 環境変数・APIキーの取得と設定
   - デプロイ手順（スクショ想定箇所を明記）
   - よくあるエラーと対処
4. **価格決定** — 競合の類似noteを3本調べ、`app-note-writer` に相場メモを作らせる。最終決定は社長。
5. **公開** — note。冒頭に「動作環境」「サポート範囲」「返金ポリシー」を明記。
6. **導線** — 各無料マガジンの末尾、Threadsプロフィール、関連note相互リンク。

## 品質チェック（公開前・社長）

- [ ] 手順どおりに他人の環境で最後まで到達できるか（できれば実機で1回なぞる）
- [ ] APIキーやシークレットがソース/スクショに写っていないか
- [ ] 無料枠の範囲・従量課金の注意を明記したか
- [ ] ライセンス表記（自作コードのライセンス、使用OSSのライセンス）
