# 【自動化指示書】新車販売台数TOP5 note下書き 月次生成

## 目的
毎月、新車販売台数TOP5データをもとに、note無料記事の下書き(マークダウン形式)を自動生成する。
記事の型は「車の話→働き方・投資的な示唆」を毎回貫くこと。

## 実行タイミング
自販連(JADA)・全軽自協が発表する前月分の車種別新車登録台数は、毎月6日前後に公表される。
**毎月8日頃**にこのワークフローを実行する(発表が遅れる場合を考慮し、数日の余裕を持たせる)。

## Step1: データ取得(販売台数)
- 情報源: 自販連(日本自動車販売協会連合会)および全軽自協(全国軽自動車協会連合会)が発表する前月の車種別新車登録・届出台数
- 登録車(普通車・小型車)と軽自動車、両方の統計を取得し、合算した「総合ランキング」でTOP5を抽出する
- 取得項目: 順位、車種名、メーカー名、販売台数、前年同月比

## Step2: データ取得(価格)
**価格帯の記載方法(修正版)**
- 上限・下限の「価格帯」ではなく、**各車の最も安いグレードの車両本体価格(下限価格のみ)** を記載する
- 表記形式: 「◯◯◯.◯万円〜」(小数点第1位まで、税込・メーカー希望小売価格ベース)
- 取得元: メーカー公式サイトの価格・グレードページを第一情報源とする。公式サイトで確認できない場合は、価格.com等の信頼できる情報源で補完し、取得元を明記する
- 直近で一部改良・値上げがあった車種は、**改良後の最新価格**を採用する(いつ時点の価格かをメモしておく)

## Step3: 記事の生成(テンプレート構造)
以下の見出し構成をテンプレートとして固定し、この順序で生成する。

1. **タイトル**: 【◯◯◯◯年◯月】新車販売台数ランキングTOP5から見える、〇〇
2. **導入**: 今月のデータである旨を一言(2回目以降は前月からの変化に軽く触れる)
3. **TOP5表**: 順位・車種・メーカー・販売台数・前年同月比・新車価格(下限)の6列
   - 表の下に「※台数は自販連・全軽自協発表の統計をもとに集計。価格は最安グレードの車両本体価格(税込)の目安」という注記を必ず入れる
4. **各車の特徴と「なぜ売れているか」**: 5台それぞれ2〜4文程度。1位のみやや厚めに深掘りする
5. **この5台に共通する構造**: TOP5全体を俯瞰して一段抽象化する(価格帯・サイズ・装備など、その月ごとに見えたパターンを言語化)
6. **働き方・投資への示唆**: 5の抽象化を、フリーランスの働き方や投資判断に接続する。以下の要素を必ず含める
   - 働き方における「地味な改善」の具体例を1つ入れる(仕事術など、抽象論で終わらせない)
   - 投資については「積立投資」「複利」など、読者が行動に移しやすい具体的なキーワードと結びつける
   - 段落の最後に、読者への問いかけを一行加える(例:「あなたの日常における『一部改良』は何ですか？」)。noteらしい読者とのコミュニケーションを生む一文として、問いかけ+小さな行動を促す一言で締める
7. **フッター**: シリーズ紹介の一文+有料noteへの導線

## Step4: 出力形式
- マークダウン形式(.md)で出力する
- ファイル名: `【年月】_車種別販売台数ランキングTOP5.md` (例: `2026年8月_車種別販売台数ランキングTOP5.md`)
- 表はマークダウンの表記法(`|`区切り)を使用する

## Step5: 前月との比較(2回目以降)
- 前回生成した記事のTOP5データを参照し、「順位の変動」「新規ランクインした車種」があれば導入部か本文中で軽く触れる
- 過去記事のストック(月次ファイル)を参照できるようにしておく

## 注意事項
- 価格情報は必ず取得日を記録し、記事内に反映した時点の情報である旨がわかるようにする
- データソースが取得できない・数値が不明瞭な場合は、その車種を記事から外すのではなく、取得できた範囲で正直に記載し、不明点は「確認中」等で明示する
- 台数データと価格データは性質が異なる(台数=公式統計/価格=メーカー公表情報)ため、情報源を分けて注記する
