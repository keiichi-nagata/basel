# 開発2部 データソース（確定版）

元になった指示書: `dev/2-cars/自動化指示書_note下書き生成.md`（内容は本ファイル＋`template.md`＋
`.claude/agents/car-column-writer.md` に反映済み）

## 実行タイミング

自販連・全軽自協の前月分 車名別データは**毎月6日前後**に公表。発表遅れを見て**毎月8日ごろ**に回す。

## 台数データ（登録車）

- 一次ソース: **自販連「ブランド通称名別ランキング」** → https://www.jada.or.jp/pages/340/
  - 順位・ブランド通称名（＝車名）・台数・前年対比 の月報PDF
  - 公表: 前月分が毎月4〜6日ごろ
  - **軽自動車と輸入車を除く**（軽は下の全軽自協から取る）
  - PDF・URL（ファイル名）が毎月変わるためスクレイピング不可 → **手動で `data/inputs/YYYY-MM.json` の `registered` に貼る**

## 台数データ（軽自動車）

- 一次ソース: **全軽自協（全国軽自動車協会連合会）「車名別 新車販売台数」** → https://www.zenkeijikyo.or.jp/statistics/
  - 通称名・台数・前年同月比 のPDF
  - 公表: 前月分が毎月5〜6日ごろ
- 同じく手動で `data/inputs/YYYY-MM.json` の `kei` に貼る

## 総合ランキングの作り方

- 登録車の車名別 ＋ 軽の車名別 を**台数で合算せず、それぞれの台数のまま1つのリストにして**台数降順ソート → 上位5
- 前年同月比は各ソースの値をそのまま引用（％）
- 前月比（順位変動・新規ランクイン）は前月の `data/YYYY-MM.json` と突き合わせて `collect.py` が算出

## 価格データ

- `dev/2-cars/prices.json` に「車名 → 最安グレードの車両本体価格（税込）・取得日・取得元」を蓄積
- TOP5に価格未登録の車種があれば `collect.py` が `【価格要確認】` を立てる → メーカー公式で確認して prices.json に追記
  - 第一情報源: メーカー公式の価格・グレードページ。無ければ価格.com等で補完し取得元を明記
  - 一部改良・値上げ直後は**改良後の最新価格**。取得日を必ず記録
- 表記: 「◯◯◯.◯万円〜」（小数第1位・税込・メーカー希望小売価格）

## 規約・引用

- 台数は「自販連・全軽自協発表の統計をもとに集計」と明記。数値は引用の範囲、順位の解釈・考察はオリジナル
- 他の自動車ニュースサイトのランキング表は転載しない（一次ソースのPDFから取る）
- 価格はメーカー公表情報。台数（公式統計）と情報源が異なるため注記を分ける

## 独自の切り口（毎号この観点で締める）

「TOP5に共通する構造 → フリーランスの働き方・積立/複利の投資判断」への接続。
価格帯・サイズ・"一部改良"のような小さな更新の積み重ね、を毎月同じ枠で読む。
