# トレード部 — 戦略メモ

売買の根拠をここに残す。実装は別リポの bot 本体。**Claude Code は戦略・コードのドラフトまで。発注はしない。**

## 全体像（【要記入】）

- 何を狙うか（例: 寄り付きのギャップ、日中のモメンタム、板の偏り）
- AIの役割（例: 前日までの材料・値動きから当日の候補銘柄をスコアリング）
- 「おすすめ株アプリ」との関係（同じスコアリングを使うのか、別ロジックか）

## エントリー条件（【要記入】）

- シグナル
- 時間帯
- 除外条件（決算日、S高/S安張り付き、低流動性 など）

## エグジット条件（【要記入】）

- 利確ルール
- 損切りルール（1トレードの最大損失）
- 時間切れ（引け前に全決済 など）

## バックテスト・検証（【要記入】）

- 検証期間・データ
- 想定勝率／損益（**note や SNS では「過去の検証値であり将来を保証しない」と明記**）
- 実運用との乖離メモ
