# トレード部 — 自動売買のガードレール（リスク上限）

bot が発注できる範囲の上限。**ここに書いた範囲外の発注はしない。** 数値の変更、bot の稼働／停止は
**社長承認必須**（`docs/decisions/0005-trade-dept-auto-daytrade.md`）。

最終確定日: 2026-09-13（委託保証金率30%を確認し全項目確定。追証の維持率%のみ引き続き要確認）

## ハード上限 — v1.1: 1銘柄・前場完結・信用取引（デイトレード信用取引＝日計り）

| 項目 | 値 | メモ |
|---|---|---|
| 購入件数の上限 | **1件** | `stock-app` の順位1位のみ採用。まずは単一銘柄で様子を見る |
| 市場フィルタの初期値 | **すべて** | 必要になれば絞る |
| 1銘柄あたりの予算額（委託保証金） | **10万円**（初期）→ **100万円**を上限に段階増額 | **株数はここから逆算**: floor(予算額÷約定価格÷100)×100株。100株も買えない銘柄はその日は見送り。100万円は生活防衛資金と分離した全損可能額 |
| エントリー方式 | **成行**（始値確定を待ってから） | 始値は寄り付き前に指定できないため指値ではなく成行。9:00〜最大**5分**、始値確定を待つ。確定しなければ発注せずその日は見送り |
| ギャップアップの許容上限 | 前日終値比 **+5%まで** | 始値確定後にこの範囲内かを判定。範囲内なら成行で新規買い、超えていたらその日は見送り（買う前に判断） |
| 利確ライン（売り指値） | 約定価格 **+5%** | 指値価格の丸め方は`strategy.md`の呼値の注意点を参照【要確認】 |
| 損切りライン（逆指値） | 約定価格 **−5%** | **1トレードの最大損失＝建玉サイズ（予算額÷委託保証金率30%＝約33.3万円）×5%≈16,700円**（保証金額基準にしない） |
| 決済セッション | **前場固定**（11:15＝11:30の15分前に成行） | 設定上は後場(15:15)も選べる作りだが当面使わない |
| 1日の最大損失額（キルスイッチ） | **20,000円** | 実際の想定損失（約16,700円）に約3,300円の余裕を見た額。保有中の全銘柄の含み損合計がこれに達したら**残る建玉をすべて**成行決済して当日終了 |
| 週の最大損失額 | **100,000円**（1日の上限×5営業日） | 到達したら週末まで停止、原因を `journal/` に記録してから再開 |
| 対象から外す | 決算発表日・ストップ高安張り付き・値幅制限で売買不可・板が薄い銘柄・信用取引不可銘柄・**デイトレード信用取引の対象銘柄でない銘柄** | bot 側で二重チェック（銘柄ごと） |
| 1日の最大発注回数 | **5回** | 新規＋決済＋訂正の合計。**規約上「同一銘柄への注文は現物・信用・執行条件を問わず5件が上限」**（利用規定第3条18項）と同じ値にした。訂正の余地はほぼ無いため慎重に |
| kabuステーションの「ソフトリミット」（ワンショット上限） | 【要確認】円（現状デフォルト300万円） | システム設定 > API 画面で設定するbroker側のハード制限。**予算額(10万円)の数倍程度、例えば30〜50万円まで下げる**。botのバグで桁を間違えても機械的に止まる多重防御 |

## 信用取引固有のガードレール

デイトレード信用取引は取引手数料無料・金利/貸株料0%（2026-09-12確認）。現物にはない、レバレッジ・追証のリスクに対応する。

| 項目 | 値 | メモ |
|---|---|---|
| 委託保証金率／実質レバレッジ上限 | **30%**（レバレッジ約3.3倍。2026-09-13確認：買い建玉＋売り建玉の合算金額の30%が必要） | 建玉サイズ＝委託保証金÷30%。上の損切り5%はこの建玉サイズに対して計算する |
| 追証（保証金維持率）ライン | 【要確認】%（一般的な信用取引は20%） | eスマート証券の基準を転記。**キルスイッチはこのラインよりずっと手前**で発動するように余裕を持たせる。v1は同日中に必ず決済するため、翌営業日をまたぐ追証判定の対象になりにくい見込みだが要確認 |
| 対象銘柄 | デイトレード信用取引は**当社（eスマート証券）指定銘柄のみ**対象 | 制度信用/一般信用の対象銘柄とは別のリスト。bot側で`stock-app`のおすすめ銘柄がこの対象かを照合する必要あり（`kabu-api-notes.md`） |
| 日計り信用の手数料・金利（品貸料） | **取引手数料無料・金利/貸株料0%**（2026-09-12確認） | 「デイトレード信用取引」商品。ただし未決済のまま持ち越すと強制決済手数料が有料になる → 11:15の強制決済ロジックの確実な実行が重要 |

## 運用ルール

- **キルスイッチ発動時**: 当日は再開しない。翌営業日に日誌へ原因を書いてから稼働。
- **API/データ異常時**（接続断・気配取得失敗・想定外レスポンス）: 新規発注を止め、保有はルール通り決済。
- **相場急変時**（サーキットブレーカー、指数の急落など）: 新規停止。判断は社長。
- パラメータ（上限・戦略）の変更は、変更内容・理由・前後の想定を社長が承認してから反映。変更履歴を下に残す。
- 週次で成績（勝率・損益・最大ドローダウン・約定数）をレビューし `journal/` に記録。
