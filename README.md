# Basel — 一人会社ワークスペース

SNS経由の収益化を目的とした、Claude Code で運営する一人会社（個人事業主）のリポジトリ。
「部署」= フォルダ + サブエージェント（`.claude/agents/`）+ 手順書（`sop/`）+ 定期実行。

## 目的（今期）

SNS（Threads / Instagram）→ note（無料マガジン + 有料note）→ 収益（有料note販売 + アフィリエイト）。

## 意思決定ルール

- **公開は必ず社長（あなた）の承認後**。エージェントはドラフトまで。
- 数値・固有名詞を含む「AI考察」は公開前にファクトチェック必須。
- アフィリンクを貼る記事・投稿は必ず広告表記を入れる（`sop/disclosure.md`）。
- 外部サービスへの送信（note公開、SNS投稿、API送信）は不可逆。実行前に確認。

## KPI（ファネル）

`finance/kpi.csv` に週次で記録。

```
SNSインプレッション → プロフィールアクセス → note閲覧 → スキ/フォロー
  → 有料note購入 / アフィリクリック → アフィリ成約（件数・金額）
```

各段の「率」の最小値が今週のボトルネック = 打ち手の対象。

## ディレクトリ

- `dev/` — 開発部（1-apps / 2-cars / 3-drama / 4-onsen）
- `marketing/` — マーケ部（threads / instagram / calendar）
- `planning/` — 企画部（ネタ候補とスコアリング）
- `finance/` — 経理部（ledger.csv / kpi.csv / reports）
- `sop/` — 全部門共通の手順書
- `docs/` — 組織・ロードマップ・意思決定ログ
- `.claude/agents/` — 各部のサブエージェント定義

## 週次リズム

月曜: `sop/weekly-close.md` に沿って前週の数字を締め、今週の優先を決める。
以降: 部門ごとの定期業務（`docs/org.md` 参照）。
